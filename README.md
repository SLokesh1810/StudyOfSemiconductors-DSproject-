STUDY OF SEMICONDUCTORS

  The data signals of semiconductors are studied with Python through necessary modules such as NumPy, Pandas, Matplotlib and sklearn. 
The data is cleaned, structured, visualized, optimzed and analysed. It carefully reviewed and analyised to find an accurate assumptions.
The data consists of 1567 examples each with 591 features.

Concepts Applied:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Statistical Correlation
- Visualization (heatmaps, pairplots, etc.)

Dataset Characteristics:
- Source: Corizo
- Format: CSV
- Size: 1567 rows 538 columns

Tools and Modules used:
- Google Colab (Python)
- Pandas, NumPy
- Matplotlib
- Sklearn
